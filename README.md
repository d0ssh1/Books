# Прочитано

Мой дневник чтения: книги, оценки из 10, отзывы, цитаты и мысли. Название, автора, год, число страниц и жанры сайт подтягивает сам из Google Books и Open Library, их всегда можно поправить вручную.

## Где хранятся данные

Все записи лежат в [`data/books.json`](data/books.json) в этом репозитории. Каждое изменение на сайте сохраняется отдельным коммитом, поэтому с телефона и с компьютера видно одно и то же, а вся история правок остаётся в Git.

Пока коммит не дошёл до GitHub (например, пропал интернет), копия хранится в браузере и отправится при следующем открытии сайта.

## Как подключить устройство

Без подключения сайт открывается только для просмотра. Чтобы вносить книги, на каждом устройстве один раз вводится токен доступа:

1. Открыть [создание токена](https://github.com/settings/personal-access-tokens/new) на GitHub.
2. В «Repository access» выбрать `Only select repositories` и этот репозиторий.
3. В «Permissions» для `Contents` поставить `Read and write`.
4. Сгенерировать токен и вставить его на сайте в разделе «Подключение к GitHub» внизу страницы.

Токен хранится только в браузере этого устройства и никуда, кроме GitHub, не отправляется.

## Экспорт

Кнопка «Экспорт всех данных» внизу страницы скачивает:

- **JSON** — полную копию, которую можно загрузить обратно;
- **таблицу CSV** для Excel и Google Таблиц;
- **текст в Markdown** со всеми отзывами, цитатами и мыслями.

## Запуск на компьютере

Сайт статический, сборка не нужна:

```
python -m http.server 8000
```

и открыть http://localhost:8000.
